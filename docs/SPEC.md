# SPEC: T5 户外地垫市场数据 -> SQLite 转换工程

## 0. 规范优先级与数据变更登记

- **业务定义不得漂移**：`要求内容.txt` 与 `新增参考的材料和内容/新增说明情况.txt` 中已经确认的分析范围、MOM/环比/YoY 定义、BSR Top100 范围、截止月份和 2027 决策要求是验收上位规范，后续数据替换不得静默改写这些业务规则。
- **用户确认的数据替换决定当前有效数据源**：数据替换不改变业务公式，但会改变由数据计算出的数值基准。SPEC 必须同时保留旧口径历史值和新口径当前值，登记发生日期、文件/批次、替换前后行数、影响月份、旧新基准差异及可比性影响；不得把旧值硬编码到新数据，也不得因保留原始文字而擅自回退用户已经替换的数据。
- **证据优先级**：当前用户明确说明 > 当前 `data/raw/` 中用户确认的有效数据 > 两份需求 `.txt` 的业务规则 > 参考 workbook 的结构/公式样例 > 历史提交。发生术语或数值冲突时必须显式记录映射或版本差异，不能择一静默覆盖。

### 0.3 最新月度比较口径覆盖（2026-09-04）

- 用户本轮明确澄清：交付物中的“月度环比/MOM”统一指**当前月份与去年同月的比较**，例如 `2026.02 vs 2025.02`、`2026.03 vs 2025.03`；该指标使用 `momBasis` 和 `mom*` 字段。
- **不再计算或展示“本月 vs 上月”的连续环比**。因此 `2026.03 vs 2026.02` 的 `+120.5%` 销量和 `+94.7%` 销售额不属于本次交付指标，必须从 JSON、Markdown、HTML、摘要和结论中移除；不得以 `chain`、`previous` 或其他别名继续输出。
- 年度 `YoY` 仍按同月份集合累计比较，例如核心 `2026.01-06 vs 2025.01-06`，不改为月度百分比的平均值。
- 本节是对此前 SPEC 中“同时展示本月 vs 上月环比”的最新用户口径覆盖。`新增说明情况.txt` 第③条保留为历史要求证据，但执行时以本节最新直接指令为准；后续如恢复上月比较，必须由用户再次明确确认并先更新 SPEC。

### 1.1 业务目标与新增要求（必须实现）

本项目不只是 Excel 转 SQLite，还必须从历年户外地垫数据生成可复核的市场分析和 2027 年经营建议。以下要求来自：

- `要求内容.txt`：原始业务要求；
- `新增参考的材料和内容/新增说明情况.txt`：2026-08-28 新增口径及修正要求；
- `新增参考的材料和内容/PP管数据-plastic-2025年-2026年.xlsx`：PP/plastic 月度、年度、BSR 前 100 和预测参考；
- `新增参考的材料和内容/PP塑料户外地垫_BSR前100年度分层与2027链接规划 (1).xlsx`：BSR 分层、父体进退层和 GENIMO 2027 规划参考。

必须交付以下四类分析：

1. **整体市场**：按月、按年度汇总销量、销售额、均价；输出用户定义的月度 MOM/环比（当前月 vs 去年同月）和年度 YoY；不输出本月 vs 上月的连续环比。
2. **PP/plastic 产品线**：商品标题按不区分大小写的完整单词 `plastic` 筛选；汇总销量、销售额、均价；输出月度/年度趋势、BSR 前 100、头部/中部/尾部及五档分层分析；分析 PP 塑料地垫趋势。
3. **高客单非 PP 产品线**：排除 PP 后，**其余全部产品都归入高客单非 PP**；丙纶、三明治等只是参考示例，不再作为额外筛选条件。输出销量、销售额、均价、趋势、BSR 前 100及分层分析，并给出高客单地垫趋势判断。
4. **GENIMO**：输出品牌指标、主力 Listing/父体识别、BSR 分层表现，并给出对 2027 年有实际意义的链接组合、库存、广告、利润和晋级/退出建议。

BSR 前 100 是核心分析范围：排名 100 之后的数据只保留作原始数据和审计用途，不进入核心趋势结论。每个类别、每个月的 BSR 前 100 独立 Listing 数必须不超过 100。

### 1.2 时间、指标和口径优先级

- 原始数据和参考材料保留到 2026.07，核心同比/环比统计及趋势结论至少统计到 2026.06，核心 `ANALYSIS_CUTOFF` 为 `202606`；2026.07 只能作为原始明细/附录或经明确标注的参考，不得静默延长核心结论周期。
- 用户在本项目中对缩写的定义优先于通用财务术语：
  - 月度 **MOM/环比**：今年 X 月 vs 去年 X 月同月，例如 2025.01 vs 2024.01、2026.02 vs 2025.02；BSR Top100 月度汇总也必须按同月比较，例如 2024.05 vs 2023.05。
  - 本月 vs 上月的连续环比不属于当前交付指标，不得在报告、HTML 或结构化 JSON 中另列。
  - 年度 **YoY**：今年与去年相同月份集合的累计比较；2026 年核心年度比较使用 2026.01-06 vs 2025.01-06。
- 每个指标必须保留跨年同月比较基准月份/周期字段（如 `momBasis`、`comparison`），避免只展示百分比而无法复核；`chainBasis/chain*` 为历史字段，不得作为当前交付指标输出。
- 月份标签必须使用可排序且无歧义的格式：内部统一 `YYYYMM`，展示时十月必须写作 `2025.10`，不得因 Excel 数值格式显示成 `2025.1`；月份顺序和缺失月份必须在审计中检查。
- 均价至少输出：SKU/Listing 平均标价，以及销售额 ÷ 销量得到的销量加权成交均价；两者不得混称为同一均价。平均标价只统计非空、可解析的价格，缺失值不得通过 `Number(null)` 等方式按 0 计入。

## 3. 数据结构 (Schema)

### 表命名规则

- 月度明细表: monthly_<YYYYMM>, 例如 monthly_202206
- TOP 销量表: top_sales_volume
- TOP 销量倍率表: top_sales_volume_ratio
- TOP 总销售额表: top_total_sales
- TOP 平均单价表: top_avg_price
- 元数据表: meta (记录每次导入的元信息)
- 工作表目录: sheet_catalog (记录工作表顺序、可见性、有效区域、分类、目标表、导入行数和跳过原因)

### 工作表范围与可见性口径

- SheetJS 的 `wb.SheetNames` 会同时返回可见表和隐藏表，不能将其长度解释为 Excel 界面可见子表数。
- 可见性读取自 `wb.Workbook.Sheets[].Hidden`：`0` 为可见，`1` 为隐藏，`2` 为深度隐藏。
- 当前源文件统计：`total_sheets=55`、可见 23、隐藏 32、有效导入 54、跳过无有效区域 1。
- 转换器应保留全部有效业务表；验证和文档必须分别报告“工作簿内部表数”“界面可见表数”“隐藏表数”“有效导入表数”。
- 空表判断必须依据工作表是否存在有效区域 `!ref`，不能只依赖固定名称 `Sheet6`。

### 通用列规则

- 第一列固定为 row_id (INTEGER, 自增主键), 保证顺序
- 第二列固定为 month_label (TEXT), 规范化月份标签
- 原始 Excel 中的列名直接转 SQLite 列名, 特殊字符替换为下划线
- 所有列类型保持 SQLite 亲和类型 (TEXT/INTEGER/REAL)
- 空值统一写 NULL
- 启用 PRAGMA journal_mode=WAL 提高并发读

## 4. 技术方案与架构

### 转换流程
```
Excel (.xlsx)
  -> xlsx.readFile() [SheetJS]
  -> 自动识别 header 行 (row 0 或 row 1)
  -> 读取工作表可见性并按内容/名称分类: TOP* / 月度 / 无有效区域 / 未识别
  -> 统一列名 (去括号/$/特殊字符)
  -> 类型推断 (数值列 -> INTEGER/REAL, 其余 -> TEXT)
  -> 批量 INSERT (事务)
SQLite (market.db)
```

### 关键决策
1. 动态 schema: 脚本启动时根据 Excel sheet 动态生成表结构, 避免遗漏新列
2. 批量 INSERT: 单事务 (BEGIN/COMMIT) 包整张 sheet, 速度与稳定性平衡
3. 空值归一: 空字符串/undefined/null 全部写 NULL; 纯空白格视为 NULL
4. header 探测:
   - 月度表: 扫描 row 0 和 row 1, 找到含"品牌"/"商品标题"/"月销量"的行
   - TOP 表: header 在 row 0 (经审计验证)
5. 月份标签规范化: 2025.6 -> 202506, 202501 -> 202501
6. 覆盖策略: `IMPORT_OVERWRITE=true` 时重建 DB；为 `false` 且目标 DB 已存在时必须拒绝执行，不能静默覆盖
7. 空 header 列保留: TOP销量 (倍率) 等表有空 header 但有数据, 自动命名为 `_col_<index>` 保留
8. 隐藏历史表纳入: 31 张隐藏月度表是历年 YoY 的必要基线，不能因隐藏状态而跳过
9. 无有效区域表跳过: 当前 `Sheet6` 没有 `!ref`，不创建业务表、不计入有效导入表数

## 6. 验收标准

1. 范围完整性: 识别 23 张可见表、32 张隐藏表；导入 50 张月度明细 + 4 张 TOP 汇总；跳过 1 张无 `!ref` 的遗留表
2. 数据完整性: 2026.01-07 之外的月度表及 4 张 TOP 表须与原始 Excel 行数一致；2026.01-07 须与 `competitor_809440.db` 的 `dedup_YYYYMM` 行数和值一致
3. 列完整性: 每个有效 sheet 写入 SQLite 的源数据列数等于 Excel 有效区域列数
4. 类型一致性: 数值列实际为 REAL/INTEGER; 文本列实际为 TEXT
5. 空值归一: 空 cell 全部为 NULL, 无空字符串
6. meta 表: 每次导入写入一条元数据记录，且表数口径不得把 55 解释为可见表数
7. DB 文件: 单文件 data/processed/market.db, 可被任何 SQLite 客户端打开
8. 抽查验证: 至少覆盖隐藏旧月、可见月份、TOP 汇总和最新月份
9. 全量验证: `tests/full_audit.js` 必须按当前有效数据源对 54 张业务表逐行逐列比对；`tests/competitor_audit.js` 必须另行核对 7 份竞品 Excel、`raw_YYYYMM` 和 `dedup_YYYYMM`；不得只在文档中声称通过
10. 覆盖保护: `IMPORT_OVERWRITE=false` 且 DB 已存在时，导入命令必须非零退出且原 DB 不变
11. 值与存储类型分别验收: 源数值与 DB 数值等值不代表 SQLite 存储类型一致；全量审计必须分别报告 value mismatch 与 numeric type change
12. 数据口径异常处置: 2026.03 - 2026.07 源 Excel 为子体级展开口径（销量虚增约 10 倍），已用竞品快照按父 ASIN 去重数据替换（见第 7 章）；替换表须保留列名交集并填充 month_label
13. 需求覆盖完整性: 交付物必须同时包含整体市场、PP/plastic、高客单非 PP、GENIMO 四个类别；每类均有销量、销售额、两种均价、跨年同月 MOM/环比、年度同周期 YoY、BSR 前100及趋势结论
14. PP 筛选验收: 标题必须按不区分大小写的完整单词 `plastic` 筛选；每月按父 ASIN 优先、否则 ASIN 去重，同一 Listing 键只能计一次；2026 父体任一变体命中时该父体归入 PP
15. 高客单验收: 排除 PP 后的所有商品都必须纳入 high 类别；不得因未命中 polypropylene/sandwich/woven/braided 或价格低于 $40 而被排除

### 7.6 BSR 前 100 分析结构（每类别 × 核心 49 月）

- 2025.05（主表导出日 2025-06-19，该表无 ASIN/父ASIN 列）源数据存在小类 BSR 同值重复（BSR=17 重复 112 行、23 重复 125 行、58 重复 156 行等，变体行共享父体名次），按名次取前 100 后全部落入 1-20，2025.05 中部 21-50/尾部 51-100 为空 → 2026.05 中部/尾部跨年同月 MOM/环比“无对应数据”；2026.05 头部跨年同月比较的基准为异常 100 行头部，仅作参考。该情形必须显式披露（分层行输出 `momGapReason`，表格显示“无对应数据”并在口径说明中解释），禁止编造或平移基准。
- 需要 2025 年竞品快照或更大范围竞品列表才能做完全同口径跨年对比
- 2026.07 虽并入整体市场趋势表，但不属于本次核心统计截止月份；2026 年结论须以 2026.01-06 为主，7月必须标记为94父体小样本，禁止计算或解读其跨口径同比、环比和累计。
